# 🛍️ Trends - Online Store (React Project)

An e-commerce web application built using **React.js** and **FakeStore API**.  
This project is developed as part of a college assignment focusing on React routing, API integration, filtering, and state management.

---

##  Features

-  Home page with hero banner
-  Product listing page (FakeStore API)
-  Search products by title & category
-  Filter products (Men, Women, Jewelry)
-  Sort products (Name & Price)
-  Product detail page
-  Similar products section
-  Cart system (add/remove/update quantity)

---

##  Tech Stack

- React.js
- React Router DOM
- Axios
- FakeStore API
- CSS3 (custom styling)
